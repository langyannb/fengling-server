## 二、API 契约（`src/api.js` 已实现，直接用）
```js
import { api, uploadFile, pickList, auth } from '../api'
const r = await api('apps')                         // GET  api.php?action=apps&_=ts
const r = await api('app_create', form, 'POST')     // POST api.php?action=app_create  (JSON body)
// r = { code, msg, data }；code === 0 成功；code === 401 时 api() 已自动清 token 并跳登录
const up = await uploadFile('upload', file, p => ...)   // 图片，成功 up.data.url
const up = await uploadFile('upload_apk', file, p => ...) // APK，成功 up.data.url
```
请求头 `Authorization: Bearer <token>`、GET 带 `&_=时间戳`、POST 为 JSON —— 全部和旧后台一致，**不要自己写 fetch**。

## 四、UI 规范
- 卡片：`<a-card :bordered="false" class="page-card">`；工具栏 `<div class="page-toolbar">`
- 表格：`<a-table :data="list" row-key="id" size="small">` + `<template #columns>` 里的 `<a-table-column>`，空态 `<template #empty>暂无数据</template>`
- 弹窗：`<a-modal v-model:visible="showX" title="..." @ok="save" :ok-loading="saving" unmount-on-close>`
- 危险操作：`<a-popconfirm content="确认删除?" @ok="del(record)">`
- 表单：`<a-form :model="form" layout="vertical">` + `<a-form-item field="name" label="名称">`
- 图片显示：`<a-image :src="url" width="60" />` 或 `<img class="thumb" :src="url" />`
- 全中文文案，保留原有字段名、action 名、校验提示语义
- 写操作成功后：`Message.success('...')` + 重新拉列表
